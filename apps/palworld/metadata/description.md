# Palworld Dedicated Server

This is a Runtipi-compatible deployment of the [thijsvanloef/palworld-server-docker](https://github.com/thijsvanloef/palworld-server-docker) container, designed to host a dedicated Palworld server easily.

### Features
* Automated installation and updates via SteamCMD on startup.
* Integrated RCON support for server administration.
* Optimized for multi-threaded CPU architectures.
* Automatic backup compatibility.

### System Requirements
* **CPU:** 4 Cores minimum
* **RAM:** 16GB minimum (32GB recommended for stable multi-player operations)
